# 전임교원 연구실적 학교별자료 전처리 도구

대학알리미에서 제공하는 원시 데이터(Excel)를 자동으로 정제하여 전임교원 1인당 SCI/SCOPUS 논문 실적을 계산하고, 전국 및 충청권 순위를 산출하는 도구입니다.

## 주요 기능

- **자동 데이터 추출**: Excel 파일에서 전임교원수 및 SCI/SCOPUS 논문 실적 자동 추출
- **캠퍼스 통합**: 다중캠퍼스 데이터를 자동으로 합산
- **1인당 실적 계산**: 전임교원 1인당 SCI/SCOPUS 논문 수 자동 계산
- **순위 산출**: 전국 순위 및 충청권 지역 순위 자동 계산
- **다중 연도 처리**: 여러 연도 데이터를 한 번에 처리하여 추이 분석 가능
- **여러 형식 출력**: Excel(2개 시트) + CSV 형식으로 결과 제공

## 설치

### 시스템 요구사항
- Python 3.10 이상

### 필수 라이브러리 설치

```bash
pip install -r requirements.txt
```

또는 다음 명령어로 개별 설치:

```bash
pip install pandas>=2.0.0 openpyxl>=3.1.0
```

## 사용법

### 1단계: 원본 데이터 준비

`Raw data/` 폴더에 대학알리미 Excel 파일을 배치합니다.

**파일명 규칙**: `YYYY년_대학_7-가.*.xlsx` 형식
- 예: `2023년_대학_7-가.xlsx`, `2024년_대학_7-가.xlsx`, `2025년_대학_7-가.xlsx`

파일명에 연도를 나타내는 `YYYY년` 패턴이 있어야 자동으로 감지됩니다.

### 2단계: 스크립트 실행

```bash
python 전임교원_연구실적_전처리.py
```

### 3단계: 결과 확인

`output/` 폴더에서 다음 파일을 확인합니다:

- `전임교원_연구실적_전처리결과.xlsx` - 메인 결과 파일 (Excel)
- `전체_대학_데이터.csv` - 전국 대학 데이터 (CSV)
- `충청권_순위.csv` - 충청권 지역 대학 데이터 (CSV)

## 출력 파일 형식

### Excel 파일 - Sheet 1: "전체_대학_데이터"

전국 모든 대학의 전임교원 및 논문 실적

| 열 | 설명 |
|---|---|
| 연도 | 데이터 연도 (YYYY) |
| 학교명 | 대학명 |
| 전임교원수 | 해당 연도 전임교원 총 수 |
| SCI/SCOPUS논문수 | SCI/SCOPUS 게재 논문 총 수 |
| 1인당논문수 | SCI/SCOPUS논문수 ÷ 전임교원수 (소수점 4자리) |
| 전국순위 | 1인당논문수 기준 전국 순위 |

### Excel 파일 - Sheet 2: "충청권_순위"

충청권(대전, 세종, 충청남도, 충청북도) 대학의 순위 정보

| 열 | 설명 |
|---|---|
| 연도 | 데이터 연도 (YYYY) |
| 학교명 | 대학명 |
| 전임교원수 | 해당 연도 전임교원 총 수 |
| SCI/SCOPUS논문수 | SCI/SCOPUS 게재 논문 총 수 |
| 1인당논문수 | SCI/SCOPUS논문수 ÷ 전임교원수 (소수점 4자리) |
| 충청권순위 | 충청권 지역 내 순위 |
| 전국순위 | 전국 순위 |

### CSV 파일

- **UTF-8-sig 인코딩**: Windows Excel에서 한글이 올바르게 표시되도록 BOM 포함
- `전체_대학_데이터.csv`: Sheet 1과 동일한 데이터
- `충청권_순위.csv`: Sheet 2와 동일한 데이터

## 처리 규칙

### 1. 대학 필터링

- **포함**: `학교종류`가 **"대학교"**인 항목만 처리
- **제외**: 사이버대학, 전문대학, 원격대학, 대학원대학교 등

### 2. 다중캠퍼스 통합

캠퍼스 표기가 다른 데이터는 자동으로 통합됩니다.

**통합 예시** (universities.json의 aliases 설정):
- `을지대학교` + `을지대학교_제2캠퍼스` + `을지대학교_제3캠퍼스` → `을지대학교` (합산)
- `건양대학교` + `건양대학교_제2캠퍼스` → `건양대학교` (합산)

### 3. 분교 처리

`is_branch: true` 속성의 대학들은 **별도 대학**으로 취급됩니다.

**분교 예시**:
- `건국대학교(글로컬)_분교` → `건국대학교(글로컬)` (독립 대학)
- `고려대학교(세종)_분교` → `고려대학교(세종)` (독립 대학)

### 4. 컬럼 자동 감지

원본 Excel의 컬럼 위치가 변경되어도 **키워드 기반 자동 감지**로 대응합니다.

- 학교명, 학교종류, 전임교원수, SCI/SCOPUS 논문수 자동 탐지
- 멀티레벨 헤더 자동 분석

### 5. 매칭되지 않은 대학 처리

universities.json에 없는 대학은:
- 콘솔에서 경고 메시지 출력
- 최종 결과에서 제외
- 처리 과정은 계속 진행

## 설정 파일

### config/universities.json

전체 대학 정보 및 캠퍼스 매핑

```json
{
  "name": "을지대학교",
  "aliases": [
    "을지대학교_제2캠퍼스",
    "을지대학교_제3캠퍼스"
  ]
}
```

| 필드 | 설명 |
|---|---|
| `name` | 정규 대학명 (결과에 표시되는 이름) |
| `aliases` | 원본 데이터의 대체 명칭 리스트 (이들은 name으로 통합됨) |
| `is_branch` (선택사항) | `true` 설정 시 분교로 처리 (별도 대학 취급) |

현재 **136개 대학** 등록

### config/regions.json

지역별 대학 리스트

```json
{
  "충청권": [
    "금강대학교",
    "배재대학교",
    "대전대학교",
    ...
  ]
}
```

- 키: 지역명 (예: `"충청권"`)
- 값: 해당 지역 대학의 정규명 리스트
- 현재 충청권: **27개 대학** 등록

## 데이터 추가 방법

### 새로운 연도 데이터 추가

```
Raw data/
├── 2023년_대학_7-가.xlsx
├── 2024년_대학_7-가.xlsx
└── 2025년_대학_7-가.xlsx  ← 새로 추가하면 자동으로 감지됨
```

파일을 `Raw data/` 폴더에 배치하면 자동으로 감지되어 처리됩니다. 스크립트를 다시 실행하면 새 데이터를 포함한 결과가 생성됩니다.

### 새로운 대학 추가

1. `config/universities.json`을 편집합니다.
2. 새 대학을 `universities` 배열에 추가:

```json
{
  "name": "새대학교",
  "aliases": ["새대학교_제2캠퍼스"]
}
```

3. 스크립트를 다시 실행하면 새 대학 데이터가 포함됩니다.

### 새로운 지역 추가

1. `config/regions.json`을 편집합니다.
2. 새 지역을 추가:

```json
{
  "수도권": [
    "서울대학교",
    "연세대학교",
    "고려대학교",
    ...
  ],
  "충청권": [...]
}
```

3. 스크립트를 다시 실행하면 새 지역 순위 정보가 자동으로 계산됩니다.

## 처리 과정

스크립트 실행 시 다음 단계를 거칩니다:

```
[1/5] 설정 파일 로드
      ├─ universities.json 읽기 (136개 대학)
      ├─ regions.json 읽기 (충청권 27개 대학)
      └─ 이름 매핑 테이블 구축

[2/5] Raw 데이터 파일 스캔
      ├─ Raw data/ 폴더 검색
      ├─ 연도 패턴(YYYY년) 추출
      └─ 파일 목록 정렬

[3/5] 연도별 데이터 처리
      ├─ Excel 파일 읽기 (헤더 자동 탐지)
      ├─ 대학교 필터링
      ├─ 캠퍼스 통합 (merge)
      └─ 1인당 논문수 계산

[4/5] 순위 계산
      ├─ 전국 순위 계산
      └─ 충청권 순위 계산

[5/5] 결과 파일 저장
      ├─ Excel 저장 (2개 시트)
      ├─ CSV 저장 (UTF-8-sig)
      └─ 완료 요약 출력
```

## 알려진 제한사항

### 청운대학교

- `regions.json`에 충청권 대학으로 등록되어 있음
- 그러나 원본 데이터에서 `"학교종류": "전문대학"`으로 분류
- "대학교" 필터링 규칙에 의해 자동으로 제외됨

### 매칭되지 않은 대학

- 약 75개의 대학(주로 국립/공립대학과 특수대학)이 원본 데이터에는 있지만 universities.json에 없음
- 예: 서울대, 충남대, KAIST, 각 지역 국립대학 등
- 콘솔 경고로 표시되며 결과에서 제외됨
- 필요시 universities.json에 추가하여 처리 가능

## 문제 해결

### "Raw data 폴더에서 Excel 파일을 찾을 수 없습니다"

- `Raw data/` 폴더 존재 확인
- Excel 파일 파일명에 `YYYY년` 패턴 포함 여부 확인
- 예: `2025년_대학_7-가.xlsx` (O), `대학_2025.xlsx` (X)

### "컬럼 탐지 실패"

- Excel 헤더 구조가 예상과 다른 경우
- 콘솔 출력의 "헤더 영역 내용"을 참고하여 구조 파악
- 필요시 `find_columns()` 함수의 키워드 조정 검토

### "'OOO'이(가) universities.json에 없습니다. 결과에서 제외됩니다"

- 대학을 처리하려면 `config/universities.json`에 정규명을 추가
- `"name"`: 정규 대학명
- `"aliases"`: 원본 데이터의 대체 명칭들

### CSV를 Excel에서 열 때 한글이 깨짐

- CSV 파일은 UTF-8-sig 인코딩(BOM 포함)으로 저장됨
- Excel에서 "데이터" → "텍스트에서" → 인코딩을 "UTF-8"로 선택하여 열기
